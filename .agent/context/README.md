# Contexto Modular

## Como Usarlo

1. Abrir `00-router.md`.
2. Leer `01-global-rules.md`.
3. Elegir un archivo de `areas/` segun la capa tecnica.
4. Elegir un archivo de `modules/` si la tarea pertenece al wizard o a formularios L-*.
5. Consultar `troubleshooting/` solo ante errores especificos.
6. Consultar `history/` solo para trazabilidad.

## Carpetas

- `areas/`: reglas tecnicas por capa.
- `modules/`: reglas funcionales por modulo.
- `troubleshooting/`: diagnosticos de errores conocidos.
- `history/`: resumenes de sesiones relevantes.

La regla vigente siempre esta en esta carpeta, no en `archive/`.
